# Simple Interest Calculator

## Project Description

The Simple Interest Calculator is a basic application that calculates simple interest based on the principal amount, rate of interest, and time period.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

## Inputs

* Principal Amount
* Rate of Interest
* Time Period

## Output

* Simple Interest
* Total Amount

## Example

If:

* Principal = 10000
* Rate = 5%
* Time = 2 years

Then:

Simple Interest = (10000 × 5 × 2) / 100 = 1000

Total Amount = 10000 + 1000 = 11000

# Contributing Guidelines

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

## How to Contribute

1. Fork the repository.
2. Create a new branch for your changes.
3. Make your changes.
4. Test your changes.
5. Commit your changes with a clear message.
6. Push your branch to GitHub.
7. Create a Pull Request.

## Bug Reports

If you find a bug, please provide a clear description of the problem and steps to reproduce it.

## Documentation Improvements

Improvements to documentation, examples, and project instructions are welcome.

## Enhancements and Ideas

Suggestions for new features and improvements are encouraged. Please describe the proposed enhancement clearly.

Thank you for contributing to the Simple Interest Calculator project!
